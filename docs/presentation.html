The Problem

  • Secrets scattered across .env files, config, and sticky notes
  • No encryption at rest — plaintext passwords in repos
  • No audit trail — who changed what, when?
  • No versioning — accidentally overwrite a key and it's gone
  • Cloud vaults are often overkill for small/mid teams

StashLock — a lightweight, self-hosted alternative.

What is StashLock?

A secure, lightweight key-value storage system (secrets vault) with a REST API, .NET client library, and command-line interface.

Features

  • AES-256 client-side encryption
  • Version history & rollback
  • TTL / auto-expiration
  • Soft delete with retention
  • Full audit logging

Ops

  • API key auth with RBAC
  • Rate limiting per key
  • Admin dashboard (Razor + HTMX)
  • Docker / docker-compose
  • SQLite — zero config DB

Server — REST API

MethodEndpointDescription
GET/Health check
GET/boxesList keys (optional ?prefix=)
POST/boxes/{key}Store content (optional TTL)
GET/boxes/{key}Retrieve content
DELETE/boxes/{key}Soft-delete
GET/boxes/{key}/metaMetadata (size, timestamps)
GET/boxes/{key}/historyVersion history
GET/boxes/{key}/history/{v}Specific version
POST/boxes/decodeDecode key + decrypt value

Auth via Authorization: Bearer <api-key> · Keys are URL-safe base64 encoded

Server — Decode Endpoint

Read secrets from any language with one HTTP call

# No base64 encoding, no crypto libraries needed
curl -X POST https://vault.example.com/boxes/decode \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"box": "myapp", "tag": "secrets", "password": "Pass123"}'
# Response: plain text — the decrypted value directly
{"DbPassword": "s3cret", "ApiKey": "abc123"}
  • box + tag required · version defaults to 00001
  • password optional — without it, returns key info + exists flag only
  • Works from Python, Go, shell scripts — no .NET client needed

Encryption Model

Plaintext JSON → AES-256
PBKDF2 key derivation → Encrypted blob → Server
stores ciphertext only
  • Algorithm: AES-256 with PBKDF2 (Rfc2898DeriveBytes)
  • Iterations: 100,000 · SHA-256
  • Key size: 256-bit key, 128-bit IV
  • Sealed mode: X25519 ECIES envelope encryption with AES-256-GCM

Default: zero-knowledge — server stores ciphertext only. Optional: /boxes/decode endpoint enables server-side decryption for non-.NET consumers.

Client Library

Deneblab.StashLock.Client

dotnet add package Deneblab.StashLock.Client
// 1. Configure — get a VaultKey
var vaultKey = VaultKey.FromEnvironment();
// or: VaultKey.FromFile("vault.key")
// or: VaultKey.FromString("box.tag.version.password")

// 2. Open — connect to the vault
var store = await SecretsStoreAsync.OpenRemoteAsync(vaultKey);

// 3. Read secrets
var dbConn = await store.GetAsync("ConnectionString");

var allSmtp = await store.GetSectionAsDictionaryAsync("Smtp");
// { "Smtp:Host": "...", "Smtp:Port": "...", "Smtp:Password": "..." }

Client — Sealed Mode

X25519 ECIES envelope encryption

// Open with keypair-based encryption
var store = await SecretsStoreAsync.OpenRemoteSealedAsync(
    box: "myapp",
    tag: "production",
    version: "00001"
);

// With encrypted local cache for offline fallback
var store = await SecretsStoreAsync.OpenRemoteSealedWithCacheAsync(
    box: "myapp",
    tag: "production",
    cacheOptions: new CacheOptions { CacheDurationMinutes = 60 }
);

CLI Tool

Deneblab.StashLock.Cli

# Install globally
dotnet tool install -g Deneblab.StashLock.Cli

# Initialize a vault directory
stashlock init ./my-vault --tags production,develop

# Generate keypairs for each tag
stashlock keygen ./my-vault

# Encrypt secrets
stashlock encode ./my-vault/secrets.json

# Decrypt secrets
stashlock decode ./my-vault/stashlock.enc.production.secrets.json

# Publish encrypted blobs to server
stashlock publish ./my-vault \
    --url http://localhost:8099 \
    --api-key YOUR_KEY \
    --expiresIn 86400

Docker Deployment

# docker-compose.yml
services:
  stashlock-server:
    image: ghcr.io/deneblab/stashlock-server:latest
    ports:
      - "8099:8080"
    environment:
      - StashLock__ApiKey=your-secret-api-key
    volumes:
      - ./app/work:/app/work   # SQLite DB + keys
      - ./app/log:/app/log     # Application logs
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/healthz"]
      interval: 30s
      timeout: 10s
      retries: 3
docker compose up -d

Getting Started

    docker compose up -d
  2. Install the CLI 
    dotnet tool install -g Deneblab.StashLock.Cli
  3. Initialize & publish secrets 
    stashlock init ./vault --tags production
stashlock keygen ./vault
# Edit vault/secrets.json with your secrets
stashlock encode ./vault/secrets.json
stashlock publish ./vault --url http://localhost:8099 --api-key KEY
  4. Read in your app 
    var store = await SecretsStoreAsync.OpenRemoteSealedAsync("myapp", "production");
var secret = await store.GetAsync("DbPassword");
